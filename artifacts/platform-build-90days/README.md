# platform-build-90days

This directory contains foundational artifacts for the new data platform:

- exec-overview.html:
  Executive overview for leadership buy-in (vision, decisions, phased roadmap, asks).

- 90day-plan.html:
  Detailed 90-day implementation plan (week-by-week).
  Focus: ontology-first, infra as code, ingestion, streaming, statement engine prototype, PCI readiness.

- maturity-model.html:
  Data platform capabilities maturity model (0–4) across 7 capabilities,
  mapped to 90-day, Q2 27, Q4 27, and 2028–2030 targets.

These are living documents; they should evolve as architecture is refined and implemented.
